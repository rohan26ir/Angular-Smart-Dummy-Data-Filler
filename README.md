# Angular-Smart-Dummy-Data-Filler

> High-conversion multi-page marketing website & interactive playground for **GhostInput · Smart Dummy Data Filler** (Chrome Extension for QA automation engineers and full-stack developers).

Built with **Angular 21 (Standalone Components, Signals)** and **Tailwind CSS**.

## ✨ Features
* **Framer-Grade Dark Aesthetic**: Looping CloudFront video background with subtle vignette and ambient gradients.
* **Modern Typography**: FSP DEMO - Podium Sharp 4.11 (`font-podium`) and Inter (`font-inter`).
* **Modular Architecture**: Clean separation between **Reusable (UI)** and **Non-Reusable (Feature)** components.
* **Interactive Form Playground**: Real-time form hydration testing with multi-persona switching (Default US, E-Commerce, Enterprise B2B).
* **Chrome Web Store Compliant**: Full Privacy Policy with host permission justifications, storage disclosures, and Limited Use certification.
* **Pages**: Home, Features, About, Testimonials, Contributors, Help & Feedback, Privacy Policy, Terms of Service.

## 🚀 Getting Started

### Prerequisites
* Node.js 20+
* npm

### Installation
```bash
# Clone the repository
git clone https://github.com/rohan26ir/Angular-Smart-Dummy-Data-Filler.git

# Navigate to project
cd Angular-Smart-Dummy-Data-Filler

# Install dependencies
npm install
```

### Development Server
```bash
npm start
# or: npx ng serve
```
Navigate to `http://localhost:4200/` in your browser.

### Production Build
```bash
npm run build
```
Production output will be generated in `dist/web-ghostinput/browser`.
